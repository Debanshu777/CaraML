The app bundles static TTF instances to give Android, iOS and Desktop the same
weights without depending on platform variable-axis selection. Generated with
FontTools 4.60.2 varLib.instancer.instantiateVariableFont:
- Bricolage Grotesque: opsz=32, wdth=100, wght=600/700/800.
- DM Sans: opsz=14, wght=400/500/600/700; italic opsz=14, wght=400.
Family/subfamily/full/PostScript name records identify the static instance.
Glyph coverage and all copyright/license metadata are retained; no subsetting.
The fonts are bundled at build time. No font network requests occur at runtime.
